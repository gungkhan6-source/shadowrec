# ShadowRec

Native high-performance screen capture pipeline for Windows.

ShadowRec is a native screen capture project built around DXGI and FFmpeg,
designed for high-performance video capture and streaming applications.

## 🚀 Features

- Native Windows screen capture
- DXGI-based capture pipeline
- FFmpeg integration
- High-performance frame processing
- RGBA/BGRA pixel format support
- Game capture support
- 32-bit cross-architecture support

## 🛠️ Technologies

- C++
- JavaScript
- Python
- DXGI
- FFmpeg
- Node.js / Native Addons

## 🎯 Project

ShadowRec is part of the NovaRec Studio ecosystem and is being developed
as a foundation for high-performance recording and streaming software.
